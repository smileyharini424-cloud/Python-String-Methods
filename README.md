# Python String Methods

## Explanation

Python provides many built-in methods for working with strings. These methods make it easier to modify, search, and process text.

## Problem Statement

Write a Python program that accepts a string from the user and demonstrates commonly used string methods.

## Features

* Converts text to uppercase
* Converts text to lowercase
* Removes extra spaces
* Replaces characters or words
* Splits a string into a list
* Finds the length of a string

## How It Works

The program uses the following string methods:

* `upper()` – converts text to uppercase
* `lower()` – converts text to lowercase
* `strip()` – removes spaces from the beginning and end
* `replace()` – replaces part of a string
* `split()` – separates a string into a list
* `len()` – returns the number of characters

## Technologies Used

* Python 3

## Program Flow

1. Start the program.
2. Read a string from the user.
3. Apply different string methods.
4. Display the results.
5. End the program.

## Sample Input

```text id="w6t1zk"

```

## Sample Output


## Key Learning

* Understanding string methods
* Using `upper()` and `lower()`
